Terasweep fits Ridge, DLinear, LightGBM regression, and TiDE on prepared numeric matrices. Its parameter sweep evaluates an ordered list of model settings using mean absolute error on a labeled validation split.

Two runs

A single fit trains a fresh model and returns predictions in input order. A sweep shares work across settings and returns the winning predictions, validation MAE, and the number of distinct fits.

Tabular models accept multiple numeric features. DLinear and TiDE accept one observed series and predict the next value. Fit a candidate using training data, choose settings on validation data, and reserve a holdout for the chosen model.
