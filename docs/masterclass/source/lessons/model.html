The calculation Ridge shares

With an intercept, Ridge centers the features and target before forming the Gram matrix (G = XᵀX) and the right-hand side (h = Xᵀy). Solving ((G + αI)w = h) gives the coefficients. The intercept is recovered from the training means.

The Gram matrix and right-hand side depend on the training data. A different α changes the diagonal and requires a new solve. Changing the intercept setting selects the raw or centered statistics.
