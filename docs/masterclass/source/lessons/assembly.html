Shared calling and output conventions




RUST LINKS BOTH KERNELS INTO ONE EXECUTABLE
core::arch::global_asm!(
    include_str!("score8_gpr.S"), options(raw)
);

let kernel: Kernel = if assembly {
    score8_asm_gpr
} else {
    score8_rust_intrinsics
};


Both kernels take the same packed thresholds, sign and absolute-value masks, and price view, and write the same output layout. Grouping, packing, caching, cost adjustment and summary reduction are shared Rust code. The notation extern "C" specifies the calling convention.

Register use and instruction order

The assembly assigns vector accumulators and keeps the position-state masks in 32-bit general-purpose registers, from which it transfers them into the AVX-512 mask registers. It schedules Boolean operations alongside accumulation and preserves separate multiplication and addition in chronological order within each lane. It uses the same precision and does not substitute FMA or use fast-math.
