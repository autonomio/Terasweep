Run the package examples

From the repository root, build the package, fit the concrete strength example, and run the ordered model plan.

make build
python3 scripts/model_run.py fit docs/examples/ridge.json
make run
make test

The example sweep has four entries and three distinct Ridge fits. Its JSON receipt returns the winning model's position in the plan and predictions in validation row order.

The optional reference audit also exercises LightGBM and TiDE. Follow the backend instructions to enable them.
