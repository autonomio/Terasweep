Sequence of implementation and validation

Fix the comparison contract→Factor dependencies→Profile→Remove repeated computations→Reduce cache storage→Choose SIMD lanes→Schedule instructions→Validate and measure scaling→Commit the evidence

Most of the native-relative ratio arises before instruction scheduling, because reuse removes computations the reference repeats. The effect of replacing intrinsics with assembly is measured separately by the controlled kernel and process comparisons.

Example results statement

On a single pinned CPU in the AMD EPYC 9V74 guest, the integrated Rust pipeline with the handwritten kernel processed one billion sampled rows in 98.286879 s, including cached failed-fit requests. A linear model calibrated on short native Ridge runs using the same matrices estimates a time ratio of approximately 63,622 under the native scoring convention. One intrinsics and assembly pair at this size leaves the size of the assembly-specific effect unresolved, while the earlier paired integration runs measured a small whole-process difference with substantial variation.
